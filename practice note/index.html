什麼是Meta? (meta 的核心概念就是：「描述某個東西本身的資訊，而不是那個東西本身。」)

Meta是指網頁的元資料，通常會放在head標籤中，包含網頁的描述、關鍵字、作者、版權等資訊。

Description

Description是指網頁的描述，通常會放在meta標籤中，讓搜尋引擎可以了解網頁的內容。

是由開發者（或程式）提供給搜尋引擎和社群平台的頁面摘要，不是 HTML 自動從內文擷取，且 Google 可能視情況改用內文作為搜尋結果描述。

Keywords

Keywords是指網頁的關鍵字，通常會放在meta標籤中，讓搜尋引擎可以了解網頁的內容。

OG

OG是指Open Graph的縮寫，用於定義網頁的社交媒體分享資訊。

OG標籤通常會放在head標籤中，包含網頁的標題、描述、圖片、網址等資訊，讓社交媒體可以正確地顯示網頁的內容。

  • og:title：網頁的標題。
  • og:description：網頁的描述。
  • og:image：網頁的圖片。
  • og:url：網頁的網址。(og:url 用來指定網頁的正式網址，避免同一內容因不同網址被社群平台誤認為不同頁面。)

CSS基本三種方法

方法一: 內嵌樣式-在head中使用style標籤

可以在HTML文件的<head>部分使用<style>標籤來定義CSS樣式。

  1. 對元素(標籤)直接修飾: 改變元素的外觀
  2. 對元素(標籤)加上class或id: 方便重複使用
  3. 加上id，選擇該id旗下的元素
  4. 選擇 id（要 #）
  • 優點: 可以讓整個網頁都套用CSS的樣式，方便統一管理
  • 缺點: 需要在HTML文件中加入style標籤，增加HTML文件的大小，且無法一次調整所有不同的page

方法二: 行內樣式

可以在HTML元素中使用style屬性來定義CSS樣式。

  • 優點: 簡單直接，適用於單一元素的樣式定義
  • 缺點: 不易維護，無法重複使用，會增加HTML文件的大小

方法三: 外部CSS檔案

可以將CSS樣式寫在一個單獨的.css檔案中，然後在HTML文件中使用<link>標籤來引入該CSS檔案。

引入方式: 在head中加入<link rel="stylesheet" type="text/css" href="styles.css">

  • 優點: 可以將CSS樣式與HTML結構分離，方便維護和重複使用，且可以一次調整所有不同的page
  • 缺點: 需要額外建立CSS檔案，增加HTTP請求次數，且需要注意CSS檔案的路徑

CSS顏色

CSS中可以使用多種方式來定義顏色，包括顏色名稱、十六進位值、RGB值和RGBA值等。

<p>CSS 覆蓋順序：!important > Inline (style="") > #id > .class > tag > *；若權重相同，後面寫的覆蓋前面。</p>

  • 內建顏色: red, blue, green, etc.
  • 十六進位值: #FFFFFF, #000000
  • RGB值: rgb(255, 0, 0), rgba(255, 0, 0, 0.5) (最後面的 0.5 是 Alpha（透明度）。)
  • HSL: 色調, 飽和度, 明度. 例如: hsl(0, 100%, 50%) 是紅色
  • color: 顏色
  • background-color: 背景顏色
  • border-color: 邊框顏色

甚麼是浮動排版?

浮動排版(Float Layout)就是利用 CSS 的 float 屬性，讓元素靠左或靠右排列，其他內容會自動繞著它。

文繞圖(Float 最常見用途)

float 最初主要用來做文繞圖，當圖片設定 float: left; 或 float: right; 時，圖片會靠左或靠右，旁邊的文字則會自動環繞圖片排列，而不是換到下一行，常見於新聞、部落格等文章排版。

網頁排版

除了文繞圖之外float 也可以用來做網頁排版，例如讓多個 div 靠左或靠右排列，製作左右欄、多欄式版面等。早期許多網站都是利用 float 完成整個頁面配置，但現在大多已改用 Flexbox 或 CSS Grid 來設計版面

排版順序

使用 float 排版時，元素會依照 HTML 的撰寫順序 依序排列。設定 float: left; 時，元素會由左往右排列；空間不足時會自動換到下一列。若設定 float: right;，元素則會依序靠右排列，後加入的元素會接續排列在前一個浮動元素旁邊。

style="clear: both;" = clear 用來清除浮動，使元素不與浮動元素並排；clear: both; 表示同時清除左、右兩側的浮動，讓元素從所有浮動元素下方開始顯示。

CSS中的Overflow?

overflow 是 CSS 用來控制內容超出元素大小時該如何顯示 的屬性。當內容超過元素設定的寬度或高度時，可以決定是顯示、隱藏、捲動或自動出現捲軸。

visible (預設)

超出的內容直接顯示，不會被裁切。

hidden

超出的內容會被隱藏，使用者看不到。

scroll

永遠顯示捲軸（水平或垂直），即使內容沒有超出，也會保留捲軸空間。

auto

只有內容超出時才會顯示捲軸，沒有超出則不顯示。

clip

超出的內容會直接裁切（剪掉），且不能透過捲動查看。與 hidden 類似，但更偏向單純裁切內容。

CSS中的定位: Position

絕對位置:

不指定 position 時，元素會依照正常排列，margin 只是調整元素之間的距離；只有 absolute、fixed 等定位方式，才會真正脫離正常排列。

position: absolute; 會讓元素脫離正常排列，不再影響其他元素的位置。通常會搭配 top、right、bottom、left 來指定元素的位置。如果父元素有設定 position: relative;，則會以父元素為基準定位；否則會以整個瀏覽器視窗為基準定位。

當子元素使用 position: absolute; 時，如果父元素設定了 position: relative;，子元素會以父元素為定位基準，搭配 top、right、bottom、left 決定位置；如果父元素沒有設定 position: relative;，則子元素會往外尋找最近有設定定位（如 relative、absolute、fixed）的祖先元素，若都找不到，就會以整個瀏覽器視窗（Viewport）作為定位基準。

固定位置:

position: fixed; 會讓元素脫離正常排列，並固定在瀏覽器視窗（Viewport）的指定位置，通常搭配 top、right、bottom、left 設定位置。即使網頁上下捲動，元素仍會固定在原來的位置，不會跟著內容一起移動，常用於返回頂端按鈕、導覽列或懸浮選單。

position: relative（相對位置）

position: relative; 會讓元素以自己原本的位置作為基準，搭配 top、right、bottom、left 進行偏移。元素雖然看起來移動了，但仍保留原本所佔的空間，不會脫離正常排列，也常作為 position: absolute; 子元素的定位基準。

position: sticky（黏性定位）

position: sticky; 結合了 relative 和 fixed 的特性。元素一開始會依照正常排列顯示，當網頁捲動到指定位置（通常搭配 top、left 等）時，元素會固定在該位置；離開父元素的範圍後，則會停止固定並跟著父元素一起結束。常用於表格標題、側邊欄或導覽列。

CSS 權重（Specificity）

當多個 CSS 規則同時套用到同一個元素時，瀏覽器會根據權重（Specificity）決定哪一個樣式生效。權重越高，優先權越高；若權重相同，則以後面撰寫的 CSS 覆蓋前面的樣式。

權重順序（由高到低）

  1. !important
  2. Inline Style（HTML 的 style=""）
  3. ID 選擇器（#id）
  4. Class、屬性選擇器、偽類（.class、[type]、:hover）
  5. 元素選擇器（div、p、h1）

權重比較

  • p → (0,0,1)
  • .box → (0,1,0)
  • #title → (1,0,0)
  • div p → (0,0,2)
  • div .box → (0,1,1)
  • #title .box → (1,1,0)

同權重時

如果兩個選擇器的權重完全相同，則以後面撰寫的 CSS 覆蓋前面的樣式。 

p {
        color: green;
    }

    p {
        color: red;
    }

最終文字會顯示為紅色。

補充

  • Visual Studio Code 滑鼠移到選擇器上時，可以查看 Selector Specificity（權重），方便判斷哪個 CSS 規則優先。
  • !important 雖然能提高優先權，但會增加樣式維護難度，因此除非必要，否則盡量不要使用。

  • ::after：在元素內容後加入內容（需搭配 content）。
  • ::marker：修改列表項目的項目符號（Marker）。

為什麼叫偽元素？

偽元素不是 HTML 中真正存在的元素，而是由瀏覽器暫時建立或選取元素的一部分，例如第一個字、第一行或前後新增的內容，因此稱為「偽（Pseudo）元素」。

CSS2 時期，偽類別與偽元素都使用一個冒號（:）。從 CSS3 開始，為了區分兩者，規定偽類別使用 :，偽元素使用 ::。不過為了相容舊版瀏覽器，像 :before、:after 等舊寫法現在仍然可以使用，但建議採用新的雙冒號寫法。

  • ::before、::after、::first-letter → 偽元素（Pseudo-element）

CSS Flexbox（彈性盒模型）

CSS Flexbox（Flexible Box Layout）是一種用來建立一維（單行或單列）版面的 CSS 排版模型。只要將父元素設定為 display: flex;，其子元素就會變成 Flex Item，可以輕鬆控制排列方向、對齊方式及元素間距，因此非常適合製作導覽列、卡片、按鈕排列及響應式版面。

基本概念

  • Flex Container：設定 display: flex; 的父元素。
  • Flex Item：Container 內的直接子元素。
  • Main Axis（主軸）：Flex Item 排列的方向，預設為水平（左 → 右）。
  • Cross Axis（交叉軸）：與主軸垂直的方向，預設為垂直（上 → 下）。

一句話記憶

Flexbox 就是先決定主軸方向，再決定主軸與交叉軸如何對齊。

flex-direction（主軸方向）

flex-direction 用來決定 Main Axis（主軸） 的方向，因此也會影響後續 justify-content 的排列方向。

  • row：水平排列，由左到右（預設）。
  • row-reverse：水平排列，由右到左。
  • column：垂直排列，由上到下。
  • column-reverse：垂直排列，由下到上。

範例

.container {
        display: flex;
        flex-direction: row;
    }

一句話記憶： flex-direction 決定 Item 要往哪個方向排列。

justify-content（主軸對齊）

控制 Main Axis（主軸） 上所有 Flex Item 的排列方式。

  • flex-start：靠主軸起點（預設）。
  • flex-end：靠主軸終點。
  • center：主軸置中。
  • space-between：第一個與最後一個貼齊兩側，其餘平均分布。
  • space-around：每個 Item 左右間距相同，因此兩端只有半個間距。
  • space-evenly：所有間距完全相同，包含左右邊界。

一句話記憶： justify-content 控制主軸上的排列位置。

align-items（交叉軸對齊）

控制所有 Flex Item 在 Cross Axis（交叉軸） 上的對齊方式。

  • flex-start：靠交叉軸起點。
  • flex-end：靠交叉軸終點。
  • center：交叉軸置中。
  • stretch：拉伸填滿交叉軸（預設）。
  • baseline：依文字基線對齊。

一句話記憶： align-items 控制所有 Item 在交叉軸上的位置。

align-self(單排)（單一 Item 對齊）

align-self 是設定在 Flex Item 上，用來覆蓋父元素的 align-items，只影響自己，不影響其他 Item。

  • auto：繼承父元素設定（預設）。
  • flex-start：靠交叉軸起點。
  • flex-end：靠交叉軸終點。
  • center：交叉軸置中。
  • stretch：拉伸填滿交叉軸。
  • baseline：依文字基線對齊。

一句話記憶： align-self 只改自己，不影響其他 Item。

align-content（多行排列）

控制多行 Flex Item 在交叉軸上的排列和對齊方式，只有在 flex-wrap: wrap; 且產生多行時才會生效。

  • flex-start：所有列靠交叉軸起點。
  • flex-end：所有列靠交叉軸終點。
  • center：所有列置中。
  • space-between：各列平均分布，第一列與最後一列貼齊兩端。
  • space-around：各列兩側保留相同空間。
  • space-evenly：各列與邊界間距完全相同。
  • stretch：各列平均拉伸填滿交叉軸（預設）。

一句話記憶： align-items 控制單排每個 Item，align-content 控制整排（多行）。

order（排列順序）

order 用來改變 Flex Item 的排列順序，而不需要修改 HTML。預設值為 0，數字越小越前面，數字越大越後面。

範例


    .item1{
        order: 2;
    }

    .item2{
        order: 1;
    }

    .item3{
        order: 0;
    }

flex-wrap（是否換行）

flex-wrap 用來決定 Flex Item 在空間不足時是否換到下一排。

  • nowrap：不換行（預設）。
  • wrap：空間不足時換到下一排。
  • wrap-reverse：空間不足時換到下一排，但排列方向相反。

範例


        .container{
            display: flex;
            flex-wrap: wrap;
        }

Flex Item 尺寸控制

除了控制排列方式之外，Flexbox 也可以控制每個 Flex Item 的大小， 主要使用 flex-grow、flex-shrink、 flex-basis 及其縮寫 flex。

flex-grow（放大比例）

flex-grow 用來決定當容器還有剩餘空間時，每個 Flex Item 可以分配多少空間。 數值越大，分配到的剩餘空間越多。

範例

.item1{
            flex-grow: 1;
        }

        .item2{
            flex-grow: 2;
        }

flex-shrink（縮小比例）

flex-shrink 用來決定當容器空間不足時，每個 Flex Item 要縮小多少。 數值越大，縮小的比例越多。

範例

.item1{
            flex-shrink: 1;
        }

        .item2{
            flex-shrink: 2;
        }

flex-basis（初始大小）

flex-basis 用來設定 Flex Item 的初始大小，Flexbox 會先以這個大小進行排列，再依照 flex-grow 或 flex-shrink 調整。

範例

.item{
            flex-basis: 200px;
        }

flex（縮寫）

flex 是 flex-grow、flex-shrink 與 flex-basis 的縮寫。

語法： 

flex: grow shrink basis;

範例

.item{
            flex: 1 1 100px;
        }

等同於： 

.item{
            flex-grow: 1;
            flex-shrink: 1;
            flex-basis: 100px;
        }

Transform（轉換）

CSS 的 transform 屬性可以改變元素的外觀與位置， 常見功能包括位移、旋轉、放大或縮小。

  1. 位移：translate()

    使用 translate() 可以移動元素的位置， 第一個數值代表左右位移，第二個數值代表上下位移。 

    transform: translate(50px, 20px);

    表示元素向右移動 50px， 並向下移動 20px。

  2. 旋轉：rotate()

    使用 rotate() 可以旋轉元素， 單位通常使用 deg，代表角度。 

    transform: rotate(45deg);

    表示元素順時針旋轉 45 度。 使用負數則會逆時針旋轉。

  3. 放大或縮小：scale()

    使用 scale() 可以改變元素的大小。 

    transform: scale(1.5);

    1.5 代表放大為原本的 1.5 倍， 小於 1 則代表縮小。

  4. 合併多個轉換效果

    多個轉換效果可以寫在同一個 transform 中， 每個效果之間使用空格分隔，不需要使用逗號。 

    transform: translate(50px, 20px) rotate(45deg) scale(1.5);

    這段程式會讓元素先位移、再旋轉，最後放大。 轉換效果的書寫順序不同，結果也可能不同。

CSS 動畫（animation）

CSS 的 animation 可以讓元素自動產生動畫效果， 常見流程為：先使用 @keyframes 定義動畫內容， 再透過 animation 套用到元素。

  1. @keyframes（關鍵影格）

    @keyframes 用來定義動畫的每個階段， 最常使用 from（開始）與 to（結束）。 

    @keyframes move {
            from {
                transform: translateX(0);
            }

            to {
                transform: translateX(200px);
            }
        }

  2. animation-name（動畫名稱）

    animation-name 用來指定要使用哪個 @keyframes 動畫。 

    animation-name: move;

  3. animation-duration（動畫時間）

    animation-duration 用來設定動畫播放多久， 常用單位有 s（秒）與 ms（毫秒）。 

    animation-duration: 2s;

    表示動畫會播放 2 秒。

  4. animation 縮寫

    可以將多個 animation 屬性合併成一行， 最基本的格式如下： 

    animation: 動畫名稱 播放時間;
    animation: move 2s;

    上面的程式等同於： 

    animation-name: move;
        animation-duration: 2s;

什麼是 RWD（Responsive Web Design）？

RWD（Responsive Web Design，響應式網頁設計）是一種網頁設計方式， 可以讓網頁根據不同裝置（電腦、平板、手機）的螢幕大小， 自動調整版面配置，讓使用者都有良好的瀏覽體驗。

  1. @media（媒體查詢）

    @media 用來根據不同螢幕尺寸， 套用不同的 CSS 樣式。 

    @media screen and (max-width: 768px) {

        }

  2. min-width（最小寬度）

    min-width 表示： 當螢幕寬度大於或等於指定寬度時，套用裡面的 CSS。 

    @media screen and (min-width: 768px) {
            body {
                background-color: lightblue;
            }
        }

  3. max-width（最大寬度）

    max-width 表示： 當螢幕寬度小於或等於指定寬度時，套用裡面的 CSS。 

    @media screen and (max-width: 768px) {
            body {
                background-color: lightgreen;
            }
        }

  4. min-width 與 max-width 一起使用

    可以同時設定最小與最大寬度， 只在指定範圍內套用 CSS。 

    @media screen and (min-width: 768px) and (max-width: 1024px) {
            body {
                background-color: lightyellow;
            }
        }

一句話記憶

min-width：螢幕寬度 ≥ 指定值。
max-width：螢幕寬度 ≤ 指定值。

瀏覽器是怎麼運作的？

瀏覽器（Browser）是一種用來瀏覽網頁的軟體，例如 Chrome、Edge、Firefox 和 Safari。 當我們輸入網址（URL）後，瀏覽器會向網站伺服器（Server）發送請求（Request）， 伺服器再回傳 HTML、CSS、JavaScript、圖片等資源給瀏覽器。 瀏覽器接收到這些資料後，會先解析 HTML 建立網頁結構（DOM）， 再解析 CSS 決定外觀，接著執行 JavaScript 讓網頁具有互動功能， 最後將所有內容繪製（Render）到螢幕上，形成我們看到的完整網頁。

運作流程

使用者輸入網址（URL）
↓
瀏覽器發送 HTTP / HTTPS Request
↓
網站伺服器（Server）收到請求
↓
伺服器回傳 HTML、CSS、JavaScript、圖片等檔案
↓
瀏覽器解析 HTML（建立 DOM）
↓
瀏覽器解析 CSS（套用樣式）
↓
瀏覽器執行 JavaScript（增加互動功能）
↓
Render（繪製畫面）
↓
使用者看到完整網頁

HTTP 請求方法（HTTP Request Methods / HTTP Verbs）

HTTP Request Method（又稱 HTTP Verb）表示瀏覽器或程式希望對伺服器執行什麼操作。 不同的方法代表不同的用途，例如取得資料、新增資料、修改資料或刪除資料。

  • GET：取得（讀取）資料。
  • POST：新增資料，並將資料放在 Request Body 中傳送。
  • PUT：完整更新一筆資料。
  • PATCH：部分更新資料。
  • DELETE：刪除資料。

常見範例

  • GET /users → 取得所有使用者
  • GET /users/1 → 取得編號 1 的使用者
  • POST /users → 新增使用者
  • PUT /users/1 → 完整修改編號 1 的使用者
  • PATCH /users/1 → 修改部分資料
  • DELETE /users/1 → 刪除編號 1 的使用者

JavaScript 與 jQuery

JavaScript 是一種網頁程式語言，主要用來讓網頁具有互動功能，例如按鈕點擊、動畫效果、表單驗證、與伺服器交換資料（API）等。現代網頁幾乎都會使用 JavaScript。

jQuery 是一個以 JavaScript 為基礎的函式庫（Library），提供許多已經寫好的功能，讓開發者能用更少的程式碼完成常見操作，例如操作 HTML 元素、修改 CSS、處理事件及製作動畫。

JavaScript 與 jQuery 比較

  • JavaScript：原生程式語言，可直接操作網頁。
  • jQuery：建立在 JavaScript 上的函式庫，讓程式碼更簡潔。

        document.getElementById("title").style.color = "red";

jQuery：


        $("#title").css("color", "red");

jQuery 是建立在 JavaScript 上的函式庫，主要目的是簡化 JavaScript 的撰寫，並解決早期不同瀏覽器之間語法與行為不一致的問題。

=== 和 == 差別

JavaScript 有兩種相等比較方式： == 和 ===。

  • ==：只比較值，必要時會自動轉換資料型別（Type Coercion）。
  • ===：同時比較值和資料型別，不會自動轉換型別，因此較嚴謹，也是實務上較常使用。

        5 == "5"      // true

💡 PS： === 對基本型別（Number、String、Boolean）會比較值與型別；對物件（Object、Array）則比較是否為同一個物件（同一個記憶體位置）。

        parseInt("12px");      // 12

Python 對照：


        int("123")       # 123
        float("3.14")    # 3.14

💡 PS： JavaScript 的 parseInt("12px") 可以讀到前面的數字並回傳 12；但 Python 的 int("12px") 會直接報錯。

直譯式（Interpreted） vs 編譯式（Compiled）

直譯式 編譯式
✅ 開發方便、修改後可直接執行 ✅ 執行速度快、效能較佳
❌ 執行速度通常較慢 ❌ 修改程式後需要重新編譯

Number（JavaScript 沒有 int 和 float）

JavaScript 的所有數字都屬於 Number 型別， 不像 Python 或 Java 會區分 int 和 float。 


        let a = 5;
        let b = 5.0;

        typeof a;   // "number"
        typeof b;   // "number"

parseInt() 和 parseFloat() 的差別只是解析方式不同， 最後回傳的型別都還是 Number。 


        parseInt("3.14");      // 3
        parseFloat("3.14");    // 3.14

        typeof parseInt("3.14");     // "number"
        typeof parseFloat("3.14");   // "number"

Python / Java 對照：

  • Python：int、float 為不同型別。
  • Java：int、float、double 為不同型別。
  • JavaScript：只有 Number 一種數字型別。

💡 PS： JavaScript 中 5 和 5.0 屬於相同型別，因此 5 === 5.0 會得到 true。

邏輯運算子（Logical Operators）

邏輯運算子用來組合多個條件判斷。

  • &&（AND）：兩個條件都要成立，結果才是 true。
  • ||（OR）：只要其中一個條件成立，結果就是 true。

        let age = 20;
        let hasTicket = true;

        age >= 18 && hasTicket;   // true

        age >= 18 || hasTicket;   // true

Python 對照：

  • && ≈ Python 的 and
  • || ≈ Python 的 or

&& 和 || 的回傳值

JavaScript 的 && 和 || 不一定回傳 true 或 false，而是回傳其中一個運算元。

  • &&（AND）：回傳第一個 Falsy 值；若全部都是真，回傳最後一個值。
  • ||（OR）：回傳第一個 Truthy 值；若全部都是假，回傳最後一個值。

        3 && 5        // 5
        0 && 5        // 0

        3 || 5        // 3
        0 || 5        // 5

💡 PS： 因此 && 和 || 不只是布林運算，也常用來選擇值。

💡 PS： && 常用於「條件成立才執行」；|| 常用於「設定預設值」。

isLogin && showProfile(); // 登入才執行

|| 指派預設值

|| 常用來設定預設值。當左邊是 Falsy 時，就會使用右邊的值。 


        let z;
        z = z || 10;

        console.log(z);   // 10
        

        let n = 20;
        n = n || 10;

        console.log(n);   // 20

n ||= 10，它跟你前面的 n = n || 10 是同一件事，只是 ES2021 新增的簡寫

💡 PS： ES2021 之後更常使用 ??（Nullish Coalescing）來設定預設值，避免 0、""、false 等合法值被誤判為 Falsy。

||：只要左邊是 Falsy 就用右邊；??：只有左邊是 null 或 undefined 才用右邊。

Python 和 JavaScript 的 or / || 主要用於條件判斷；設定預設值時也可以使用，但如果 0、False、"" 等是合法值，就不要使用，Python 建議用 if x is None，JavaScript 建議用 ??（Nullish Coalescing）。

score ??= 100;

三元運算子（Ternary Operator）

三元運算子是 if...else 的簡寫，用來根據條件回傳不同的值。 


        條件 ? 成立時的值 : 不成立時的值
        

        let age = 20;

        let result = age >= 18 ? "成年" : "未成年";

        console.log(result);   // 成年

Python 對照：


        result = "成年" if age >= 18 else "未成年"

補充

  • console.log("x:", 2) ≈ Python 的 print("x:", 2)。
  • JavaScript 也支援複合指定運算子（Compound Assignment Operators）。

        x += 1;   // x = x + 1
        x -= 1;   // x = x - 1
        x *= 2;   // x = x * 2
        x /= 2;   // x = x / 2
        x %= 2;   // x = x % 2
        x **= 2;  // x = x ** 2

💡 PS： 上述運算子與 Python 的 +=、-=、*=、/=、%=、**= 用法幾乎相同。

Chapter 3 控制流程

條件判斷（if、else if、else、switch）

JavaScript 可使用 if、else if、else 或 switch 進行條件判斷。 當需要判斷同一個變數的多種情況時，通常使用 switch 會更清楚。

Python 對照：

  • Python 使用 if、elif、else。
  • Python 沒有傳統的 switch（Python 3.10 起提供 match-case）。

💡 PS： Python 的 break 只能跳出 for、while；Java 和 JavaScript 的 break 還可以跳出 switch，避免程式繼續執行下一個 case。

for 迴圈（for Loop）

for 用來重複執行程式碼，通常知道要執行幾次時使用。 


        for (let i = 0; i < 5; i++) {
            console.log(i);
        }

語法：


        for (初始值; 條件; 更新) {
            // 要重複執行的程式
        }

Python 對照：


        for i in range(5):
            print(i)

💡 PS： JavaScript 的 for 比 Python 更自由，可以自行控制初始值、條件與更新方式。

📖 MDN 中文： for - MDN Web Docs

i++ 與 ++i

  • i++（後置遞增）：先使用目前的值，再加 1。
  • ++i（前置遞增）：先加 1，再使用新的值。

        let i = 5;

        console.log(i++);   // 5
        console.log(i);     // 6

        let j = 5;

        console.log(++j);   // 6
        console.log(j);     // 6

💡 PS： 如果只是單獨寫 i++; 或 ++i;，效果完全相同，只有放在運算式中才有差別。

字串與數字相加

JavaScript 可以直接將字串與數字使用 + 相加，結果會變成字串（String）。 


        "Age: " + 18      // "Age: 18"

        "5" + 3           // "53"

        5 + "3"           // "53"

Python 對照：


        # Python 會報錯
        "Age: " + 18

💡 PS： 只要其中一個是字串，+ 就會進行字串串接（Concatenation），最後結果為 String。

do...while 迴圈

do...while 會先執行一次程式碼，再判斷條件是否繼續執行。 


        let i = 1;

        do {
            console.log(i);
            i++;
        } while (i <= 5);

與 while 的差別：

  • while：先判斷條件，再決定是否執行。
  • do...while：先執行一次，再判斷條件。

        let i = 10;

        while (i < 5) {
            console.log(i);
        }
        // 一次都不會執行

        do {
            console.log(i);
        } while (i < 5);
        // 會執行一次

Python / Java 對照：

  • Python：沒有 do...while，通常使用 while True + break 模擬。
  • Java：有 do...while，語法與 JavaScript 幾乎相同。

什麼時候使用？

  • 至少要執行一次的情況，例如選單、使用者輸入、遊戲主迴圈等。

💡 PS： 由於 JavaScript 和 Python 大多可用 while 搭配其他寫法完成，因此 do...while 在實務上較少使用。

Chapter 4 函式 Function

DRY（Don't Repeat Yourself）

DRY（Don't Repeat Yourself）是一種程式設計原則， 表示不要重複寫相同的程式碼，可以使用函式（Function）重複利用程式。

💡 PS： 當相同程式碼重複出現時，通常可以考慮將它整理成一個函式。

函式（Function）

函式是一段可以重複呼叫執行的程式碼。 


        function sayHello() {
            console.log("Hello");
        }

        sayHello();

Python / Java 對照：

  • JavaScript：function hello() { }
  • Python：def hello():
  • Java：public static void hello() { }

💡 PS： 呼叫函式時，記得加上 ()，例如 sayHello()。

Expression（運算式）與 Statement（敘述）

  • Expression（運算式）：會產生一個值（Value）。
  • Statement（敘述）：執行一個動作，不一定會產生值。

        // Expression
        2 + 3
        x * 10

        // Statement
        let x = 5;
        if (x > 0) {
            console.log(x);
        }

Python / Java 對照：

  • Expression：2 + 3、a * b
  • Statement：if、for、while、變數宣告等。

💡 PS： 一般來說，Expression 有回傳值；Statement 是執行動作。

函數宣告方式一：陳述式（Function Declaration）

使用 function 直接宣告函數。 

        function sayHello() {
            console.log("Hello");
        }

        sayHello();

函數陳述式具有 Hoisting（提升）， JavaScript 會先處理函數宣告，因此可以在函數宣告之前呼叫。 

        sayHello();

        function sayHello() {
            console.log("Hello");
        }

函數宣告方式二：表達式（Function Expression）

將一個函數當成「值」，存進變數裡。 

        const sayHello = function() {
            console.log("Hello");
        };

        sayHello();

函數表達式通常要在宣告之後才能使用， 因為變數還沒有取得這個函數之前，無法呼叫它。 

        const sayHello = function() {
            console.log("Hello");
        };

        sayHello();   // ✅ 執行函數

有括號和沒有括號的差別

        sayHello();   // 執行函數
        sayHello;     // 取得函數本身，不執行

() 代表「呼叫函數」。 沒有 () 時，代表取得或傳遞這個函數本身。 

        const a = sayHello;    // 把函數傳給 a
        const b = sayHello();  // 執行函數，把回傳值給 b

什麼時候使用？

Function Declaration： 一般函數最常使用，寫法簡單，而且可以在宣告前呼叫。

Function Expression： 當函數需要存進變數、傳給其他函數，或當作資料使用時很常見。

Python 和 JavaScript 都可以把「函數當成值」：有 () 是執行函數，沒 () 是傳遞函數本身；import 只是把函數引入目前的程式，而「傳入函數」是讓另一個函數決定何時、在什麼情況下執行它。

我要自己使用函數 → import 後直接 func()；我要讓另一個函數「之後幫我執行／把它當規則」→ 傳 func。

全域與區域變數

全域變數（Global Variable）： 宣告在函數外，可以在程式的多個地方使用。

區域變數（Local Variable）： 宣告在函數或區塊內，只能在特定作用域中使用。

window 物件

在瀏覽器中，window 是代表目前瀏覽器視窗的全域物件（Global Object）， 很多瀏覽器提供的功能都放在裡面。 

        window.alert("Hello");
        window.console.log("Hello");

        // 平常可以省略 window
        alert("Hello");
        console.log("Hello");

使用 var 在傳統瀏覽器 Script 的全域宣告變數時， 通常也會成為 window 的屬性。 

        var x = 10;

        console.log(x);         // 10
        console.log(window.x);  // 10

但 let、const 宣告的全域變數， 不會變成 window 的屬性。 

        let y = 20;

        console.log(y);         // 20
        console.log(window.y);  // undefined

直接寫 z = 1

在非嚴格模式下，如果沒有先使用 var、let 或 const 宣告，直接寫 z = 1， 可能會在全域物件 window 上建立一個屬性。 

        z = 1;

        console.log(z);         // 1
        console.log(window.z);  // 1

這不是正常的變數宣告方式，容易造成錯誤，應該使用 let 或 const。

回呼函數 Callback Function

Callback Function（回呼函數）： 把一個函數傳給另一個函數，讓對方在適當的時機再執行它。 

        function heyFunc(myFunction) {
            myFunction("Hi!!");
        }

        heyFunc(alert);

這裡不是寫 alert()，因為不是現在執行， 而是把 alert 函數傳給 heyFunc， 再由 heyFunc 決定何時執行。

常見例子：addEventListener

        button.addEventListener("click", function() {
            alert("按鈕被按下了！");
        });

addEventListener() 接收一個 Callback Function， 我們不是現在執行它，而是把函數交給瀏覽器， 等使用者真的 click 按鈕時，瀏覽器才呼叫這個函數。

匿名函式（Anonymous Function）

匿名函式就是沒有名字的函式，通常用在「只需要使用一次」或當作 Callback 傳給其他函式時。

基本格式：

        function(參數) {
            // 要執行的程式
        }

例如：

        button.addEventListener("click", function() {
            alert("按鈕被按下了！");
        });

這裡的 function() {...} 沒有函式名稱，所以是匿名函式。 它被當成 Callback 傳給 addEventListener()， 等到按鈕被點擊時才會執行。

立即函式 IIFE（Immediately Invoked Function Expression）

IIFE 是建立後立刻執行，而且通常只執行一次的函式。 不需要另外用變數接住，也不是等待事件發生的 Callback。

真正的特色還是：「我需要一個暫時的 Function Scope，而且只執行一次，所以不用特別幫函式取名字。」

基本格式：

        (function() {
            console.log("立即執行");
        })();

第一組 ()：把 function(){...} 變成一個 Function Expression。

第二組 ()：呼叫這個函式，讓它立刻執行。 

        (function() {
            // 函式
        })();
        // ↑ 第一個 () 包住函式
        //  ↑ 最後的 () 執行函式

為什麼要使用 IIFE？

主要用途是建立自己的 Function Scope， 讓裡面的變數不會跑到全域（Global Scope），避免變數名稱互相衝突。 

        (function() {
            var name = "Kevin";
            var count = 10;
        })();

        console.log(name); // ❌ 外面無法使用

這種做法稱為避免污染全域作用域（Global Scope Pollution）。

IIFE 與 jQuery

以前很常使用 IIFE 包住 jQuery 程式， 並把全域的 jQuery 傳進去，讓函式內可以安全地使用 $。 

        (function($) {

            $("#button").click(function() {
                alert("Hello");
            });

        })(jQuery);

外面的 jQuery 傳進函式後， 在函式內用參數名稱 $ 代表它。 因為這個 $ 只存在於 IIFE 的作用域內， 不容易和其他也使用 $ 的套件產生衝突。

$ 只是變數名稱，沒有特殊語法意義；jQuery 習慣用 $ 作為 jQuery 的簡寫。

變數提升 Hoisting

JavaScript 執行前會先處理變數宣告，這個現象稱為 Hoisting（提升）。

var 的提升

        console.log(a); // undefined
        var a = 10;

var 的「宣告」會被提升，而且一開始會被初始化成 undefined，但真正的賦值 = 10 不會提升。 

        // 可以概念上理解成：

        var a;          // a 已存在，值是 undefined

        console.log(a); // undefined

        a = 10;

let / const 的提升

        console.log(a); // ❌ ReferenceError
        let a = 10;

let、const 其實也會被提升， 但在程式執行到宣告之前不能使用。 這段範圍稱為 TDZ（Temporal Dead Zone，暫時性死區）。

為什麼函數裡有時候讀不到外面的變數？

正常情況下，函數可以讀取外層／全域變數。 

        var a = 10;

        function test() {
            console.log(a); // 10
        }

        test();

但是如果函數內又宣告了同名變數， 內部變數會遮住外面的變數（Shadowing）。 

        var a = 10;

        function test() {
            console.log(a); // undefined
            var a = 20;
        }

        test();

因為函數內的 var a 會被提升， 所以可以概念上理解成： 

        var a = 10;

        function test() {
            var a;          // 內部 a 被提升，現在是 undefined

            console.log(a); // 找到內部 a，所以不會再找外面的 a

            a = 20;
        }

Chapter 5 JS 中的物件與陣列

Object（物件）

JavaScript 的 Object 可以把多個相關資料放在一起。
格式是 key : value，一個 key 對應一個 value。

基本格式： 
        let dog = {
            name: "Mochi",
            age: 3,
            color: "white"
        };
可以先把 JavaScript Object 想成 Python 的 dict： 
        # Python
        dog = {
            "name": "Mochi",
            "age": 3
        }
        
        // JavaScript
        let dog = {
            name: "Mochi",
            age: 3
        };
但是要注意：
  • Python 把這種資料結構叫做 dict
  • JavaScript 沒有把它叫 dict，而是叫做 Object
  • JS Object 不只可以存資料，也可以存 function

Object 和 Class 有什麼不同？

JavaScript 有 class，但是 Object 不一定要透過 class 建立。

例如直接建立一個 Object： 
        let dog = {
            name: "Mochi",
            age: 3
        };
這個 dog 已經是一個 Object，不需要先寫 class。

如果需要大量建立相同結構的物件，才比較適合使用 class： 
        class Dog {
            constructor(name, age) {
                this.name = name;
                this.age = age;
            }
        }

        let dog1 = new Dog("Mochi", 3);
        let dog2 = new Dog("Lucky", 5);
可以簡單理解成： 
        Object → 一個實際的物件
        Class  → 建立很多相似 Object 的模板
PS：JavaScript 的 class 是 ES6（ES2015）加入的語法。

Object 可以存 Function

JavaScript 中 function 本身也是一種值（value），所以可以存進 Object。 
        let dog = {
            name: "Mochi",
            age: 3,

            bark: function() {
                console.log("Woof!");
            }
        };
這裡： 
        name → "Mochi"
        age  → 3
        bark → function
Object 裡面的 function 通常稱為 method（方法）。

取得 Object 的屬性

有兩種主要方式： 1. Dot notation（點語法） 
        dog.age
        dog.name
2. Bracket notation（中括號語法） 
        dog["age"]
        dog["name"]
兩種都可以： 
        console.log(dog.age);      // 3
        console.log(dog["age"]);   // 3

什麼時候一定要使用 []？

如果 key 是存在變數裡面，要使用 []： 
        let key = "age";

        console.log(dog[key]);   // 3
如果寫： 
        dog.key
JS 會真的去找名字叫做 "key" 的屬性，而不是變數 key 裡面的 "age"。

呼叫 Object 裡面的 Function

假設： 
        let dog = {
            bark: function() {
                console.log("Woof!");
            }
        };
有括號： 
        dog.bark();
代表 執行 function。 沒有括號： 
        dog.bark
代表 取得 function 本身，不會執行。 因為 JavaScript 中 function 本身就是一個 value，所以可以被取得、儲存、傳遞。 例如： 
        let myFunction = dog.bark;

        myFunction();   // Woof!

增加 / 修改 Object 的屬性

Object 建立之後還可以繼續增加屬性。 使用點： 
        dog.color = "white";
        dog.weight = 10;
使用 []： 
        dog["height"] = 30;
也可以增加 method： 
        dog.run = function() {
            console.log("running");
        };
之後： 
        dog.run();
PS：不是「一般值用 []、function 用 .」。
點和 [] 都可以操作屬性，不管裡面放的是普通值還是 function。 例如下面全部合法： 
        dog.age = 3;
        dog["age"] = 3;

        dog.bark = function() {};
        dog["bark"] = function() {};
一般情況通常優先使用 點語法，比較簡單： 
        dog.name
        dog.age
        dog.bark()
需要動態 key 或特殊名稱時，再使用 []： 
        dog[key]
        dog["first-name"]

Symbol 是什麼？

Symbol 是 ES6 加入的一種 Primitive type。
它可以建立一個唯一的值。 
        let a = Symbol("id");
        let b = Symbol("id");

        console.log(a === b);   // false
即使兩個 Symbol 寫一樣的描述，它們仍然不是同一個值。 初學階段先記： Symbol = 用來建立唯一識別值的 Primitive type。 目前不需要深入，實際開發中比 string、number、boolean 少見很多。

Object vs Python dict

可以先這樣對照： 
        Python dict             JavaScript Object

        dog["age"]              dog["age"]
                                dog.age

        key : value             key : value

        可以存 function          可以存 function

        稱為 dict                稱為 Object
所以看到： 
        let dog = {
            name: "Mochi",
            age: 3
        };
初學時可以想成： 「很像 Python dict 的 JavaScript Object。」 但正式名稱要記得叫 Object，不是 dict。

        let data = [1, 2];

Chapter 6 進階陣列方法

補充：Function、Constructor 與 Prototype

Function 也可以有 Property

JavaScript 的 Function 不只是「一段可以執行的程式」， Function 本身也是一種 Object，因此也可以擁有自己的 Property。 

function hello() {
            console.log("Hello");
        }

        hello.age = 20;

        hello();          // Hello
        console.log(hello.age); // 20

所以 Function 可以同時：
1. 使用 () 執行
2. 使用 . 存取自己的 Property

Constructor Function

Constructor Function 並不是特殊的 Function 宣告語法， 普通 Function 使用 new 呼叫時，就可以扮演 Constructor， 用來建立新的 Object。 

function Person(name) {
            this.name = name;
        }

        const p = new Person("Kevin");

        console.log(p.name); // Kevin

new Person() 會建立新的 Object， 並讓 Function 裡面的 this 指向這個新 Object。

Prototype

Function 可以有一個 prototype Property。 Constructor 建立出的 Object，可以透過 Prototype 使用共用的方法。 

function Person(name) {
            this.name = name;
        }

        Person.prototype.sayHi = function() {
            console.log("Hi " + this.name);
        };

        const p = new Person("Kevin");

        p.sayHi(); // Hi Kevin

可以簡單理解： 

Person                     // Function
        └── prototype              // Property，裡面是一個 Object
            └── sayHi              // Property，裡面是一個 Function
回到 Array

JavaScript 內建的 Array 本身也是 Constructor Function， 而 map()、push()、pop() 等共用方法放在 Array.prototype 上。 

Array                      // Constructor Function
        └── prototype
            ├── map
            ├── push
            └── pop

所以 Array.prototype.map 可以理解成： 取得 Array 的 prototype Property， 再取得裡面的 map Property（Function）。

陣列進階方法 map()

map()：對 Array 中的每一個元素執行同一個函數， 並把結果組成一個新的 Array。

map() 是 JavaScript Array 內建的方法， 完整名稱為 Array.prototype.map()。

基礎的 for 迴圈也可以做到相同的事情， map() 只是提供更簡潔的寫法。

Array.prototype.map()

Array.prototype.map() 的意思是： map() 是定義在 Array prototype 上的方法， 所以所有 Array 都可以使用 .map()。

基本格式
const newArray = oldArray.map(function(element) {
            return 改造後的值;
        });

例如：

const numbers = [1, 2, 3];

        const result = numbers.map(function(x) {
            return x * 2;
        });

        console.log(result);  // [2, 4, 6]
        console.log(numbers); // [1, 2, 3] 原本 Array 不變

重點： map() 不會直接修改原本的 Array， 而是回傳一個新的 Array。

可以想成概念上： 

const result = [];

        for (const x of numbers) {
            result.push(x * 2);
        }

※ 可以用「建立新 Array，再逐項加入結果」來理解， 但實際 JavaScript 引擎底層不一定真的使用 push() 實作。

Python 對比

Python 也有 map()：

numbers = [1, 2, 3]

        result = list(map(lambda x: x * 2, numbers))
        # [2, 4, 6]

但 Python 更常看到 List Comprehension：

result = [x * 2 for x in numbers]
        # [2, 4, 6]

簡單記： JavaScript map() = 每一項做相同轉換 → 回傳新的 Array。

forEach()

forEach() 是 JavaScript Array 的內建方法， 會把 Array 的每個元素依序傳入 Function 執行。 

const numbers = [10, 20, 30];

        numbers.forEach(function(x) {
            console.log(x);
        });

可以理解成： 「每一個元素都執行一次這個 Function」。

forEach() 不會建立新的 Array，回傳值是 undefined。 如果需要把每個元素轉換後產生新 Array，通常使用 map()。 

const numbers = [1, 2, 3];

        const a = numbers.forEach(function(x) {
            return x * 2;
        });

        console.log(a); // undefined
Java / Python 對比

JavaScript 其實也有類似 Java enhanced for / Python for 的語法， 叫做 for...of。 

// JavaScript
        for (const x of numbers) {
            console.log(x);
        }

        // Python
        for x in numbers:
            print(x)

        // Java
        for (int x : numbers) {
            System.out.println(x);
        }

所以：
for...of → 是迴圈語法
forEach() → 是 Array 的方法，需要傳入 Function

forEach() 裡面為什麼有 Function？
numbers.forEach(function(x) {
            console.log(x);
        });

因為 forEach() 需要你傳入一個 Function， 告訴它「每個元素要做什麼」。 這個 Function 稱為 Callback Function。

每執行一次 Callback，x 就代表目前的元素。

Function Scope 與 var

JavaScript 的 var 是 Function Scope， 也就是 Function 的 { } 會形成它的作用域。 

function test() {
            var x = 10;
        }

        console.log(x); // ❌ 找不到 x

但是一般的 if、for 的 { } 不會限制 var： 

if (true) {
            var x = 10;
        }

        console.log(x); // 10

let 和 const 是 Block Scope， 在 { } 建立的 block 中宣告時，只能在該 block 內使用 

if (true) {
            let x = 10;
        }

        console.log(x); // ❌ 找不到 x

※ forEach() 並沒有規定一定要使用 var。 現代 JavaScript 通常更推薦使用 let 或 const。

用 filter() 來過濾資料

filter() 是 Array 的內建方法， 用來篩選出符合條件的元素。

一樣需要傳入一個 Callback Function， Callback 的回傳值會被判斷成 true 或 false： 

true  → 保留這個元素
        false → 不保留這個元素

最後 filter() 會把所有被保留的元素， 組成一個新的 Array。 

const numbers = [1, 2, 3, 4, 5];

        const result = numbers.filter(function(x) {
            return x > 3;
        });

        console.log(result); // [4, 5]

上面的 x > 3 會產生 Boolean： 

1 > 3 → false ❌
        2 > 3 → false ❌
        3 > 3 → false ❌
        4 > 3 → true  ✅
        5 > 3 → true  ✅

        最後 → [4, 5]

簡單記： filter() = 每一項做條件判斷 → true 留下 → 回傳新的 Array。

JS 常用 .filter()；Python 雖然有 filter()，但通常更常用 list comprehension。

JS 很喜歡 array.method(callback)；Python 很多時候偏向 for / comprehension。

find()

find() 用來找到第一個符合條件的元素。 一樣會傳入 Callback Function，利用 true / false 判斷是否符合條件。 

const numbers = [1, 5, 8, 10];

        const result = numbers.find(function(x) {
            return x > 6;
        });

        console.log(result); // 8

找到第一個符合條件的元素後就會停止搜尋。 如果完全找不到，會回傳 undefined。

find() vs filter()：
find() → 找第一個符合的元素 → 回傳元素
filter() → 找所有符合的元素 → 回傳新的 Array

Python 對比

Python 的 list 沒有 JavaScript 這種 .find()， 通常可以使用 next() 搭配 generator expression： 

numbers = [1, 5, 8, 10]

        result = next((x for x in numbers if x > 6), None)

        print(result) # 8

Python 也很常直接使用 for 找到後 break。

reduce()

reduce()：把 Array 中的所有元素一步一步累積成一個結果。 常用於加總、計算總數等。

基本格式：

array.reduce(function(accumulator, currentValue) {
            return 新的累積結果;
        }, 初始值);

accumulator：目前累積的結果
currentValue：目前處理到的元素

例如加總：

const numbers = [1, 2, 3, 4];

        const total = numbers.reduce(function(sum, x) {
            return sum + x;
        }, 0);

        console.log(total); // 10
0 + 1 → 1
        1 + 2 → 3
        3 + 3 → 6
        6 + 4 → 10

瀏覽器 Debug 方法

可以在瀏覽器 DevTools 的 Sources 中設定 Breakpoint， 讓程式執行到指定位置時暫停。

暫停後可以使用 Watch， 加入想觀察的變數或 Expression， 再一步一步執行程式，查看值如何變化。

Array.prototype 是什麼？

Array.prototype 是 Array 共用方法所在的 Prototype Object， 例如 map()、filter()、push() 等。 

Array.prototype
        ├── map()
        ├── filter()
        ├── push()
        ├── pop()
        └── ...

也可以自己在 Array.prototype 上加入方法， 讓所有 Array 都能使用。 

Array.prototype.hello = function() {
            console.log("Hello");
        };

        const numbers = [1, 2, 3];
        numbers.hello(); // Hello

※ 雖然可以修改 Array.prototype， 但實務上通常不建議隨意修改內建 Prototype， 避免和其他程式或未來的內建方法產生衝突。

Chapter 7 初探 ES6

新增變數的宣告：let 和 const

ES6 新增了 let 和 const， 主要改善以前 var 在作用域上的問題。 

var   → Function Scope
        let   → Block Scope { }
        const → Block Scope { }

var 只受到 Function Scope 限制， 所以放在 if、for 等 Block 裡， 外面仍然可能存取到。 

if (true) {
            var a = 10;
        }

        console.log(a); // 10

let 和 const 是 Block Scope， 只存在於宣告它的 { } 中。 

if (true) {
            let a = 10;
            const b = 20;
        }

        console.log(a); // ❌
        console.log(b); // ❌
const

const 代表變數不能被重新賦值（reassignment）。 

const a = 10;

        a = 20; // ❌ Error

但如果 const 存的是 Object 或 Array， Object / Array 裡面的內容仍然可以修改。 

const numbers = [1, 2, 3];

        numbers.push(4); // ✅
        numbers[0] = 100; // ✅

        numbers = [5, 6]; // ❌ 不能重新賦值

所以簡單記： const 固定的是變數的綁定（binding），不是讓整個 Object 變成不可修改。

※ JavaScript 一般變數使用 camelCase； 真正想表示「固定設定值」的常數才常使用全大寫，例如 MAX_SIZE。

和 Python / Java 對比
JavaScript → const
        Java       → final
        Python     → 沒有真正的 const 關鍵字
                    通常用 MAX_SIZE 這種大寫命名表示「請不要修改」

解構賦值 Destructuring Assignment

解構賦值是 ES6 提供的語法， 可以快速把 Array 或 Object 裡面的資料取出來並存進變數。

Array 解構
let [a, b, c] = [1, 2, 3];

        console.log(a); // 1
        console.log(b); // 2
        console.log(c); // 3

Array 解構是按照位置取值： 

[a, b, c] = [1, 2, 3]
 ↓  ↓  ↓
 1  2  3

JavaScript 不能直接寫： 

a, b, c = 1, 2, 3; // ❌ 不是 Python 那種多重賦值

因為 JavaScript 的逗號本身有其他語法意義， ES6 因此使用 Array 的 [ ] 語法表示： 「把右邊資料按照位置拆開」。

Python 則原生支援 unpacking：

a, b, c = 1, 2, 3
Object 解構
let {a, b} = {
            a: 111,
            b: 222
        };

        console.log(a); // 111
        console.log(b); // 222

Object 解構不是按照位置，而是按照Property Name尋找。 


        {
            a: 111,
            b: 222
        }

        a → 找到 property "a" → 111
        b → 找到 property "b" → 222

{a, b} 是簡寫。 可以概念上理解成： 

let {
            a: a,
            b: b
        } = {
            a: 111,
            b: 222
        };

左邊的意思： 


        a: a
        ↑  ↑
        │  └── 建立的變數名稱
        └───── 要找的 Property Name

如果 Property Name 和變數名稱相同， 就可以簡寫成 {a}。

也可以故意使用不同的變數名稱：

const user = {
            name: "Kevin",
            age: 20
        };

        const {name: userName, age: userAge} = user;

        console.log(userName); // Kevin
        console.log(userAge);  // 20

簡單記：
Array 解構 → 按照位置拆
Object 解構 → 按照 Property Name 拆

for...of 和 for...in

for...of

for...of 用來遍歷 Iterable（可迭代物件）的值。 常見的 Iterable 有 Array、String、Map、Set 等。 

const numbers = [10, 20, 30];

        for (const value of numbers) {
            console.log(value);
        }

        // 10
        // 20
        // 30

簡單記：for...of → 直接取得值 value。

for...in

for...in 用來遍歷 Object 的 可列舉 Property Key。 

const user = {
            name: "Kevin",
            age: 20
        };

        for (const key in user) {
            console.log(key);
        }

        // name
        // age

如果要取得 value，可以再使用： 

for (const key in user) {
            console.log(user[key]);
        }

        // Kevin
        // 20
Array 使用時的差別
const numbers = [10, 20, 30];

        for (const x of numbers) {
            console.log(x);
        }
        // 10, 20, 30 → value


        for (const x in numbers) {
            console.log(x);
        }
        // "0", "1", "2" → property key

所以遍歷 Array 的內容通常使用 for...of， 不建議用 for...in 當一般 Array 迴圈。

和 Python 對比
# Python list
        for x in numbers:
            print(x)

        # 很像 JavaScript：
        for (const x of numbers) {
            console.log(x);
        }

Python 的 for...in 和 JavaScript 的 for...in 意思不同。 

# Python dict：直接遍歷會取得 key
        for key in user:
            print(key)

        # JavaScript Object
        for (const key in user) {
            console.log(key);
        }

簡單記：
JavaScript for...of → Iterable 的 value
JavaScript for...in → Object 的 property key
Python for...in → 從 iterable 一個一個取值

Iterator 與 next()

for...of 背後會使用 Iterator， 一次取得一個值。 

const numbers = [1, 2, 3];

        const iterator = numbers[Symbol.iterator]();

        console.log(iterator.next());
        // { value: 1, done: false }

        console.log(iterator.next());
        // { value: 2, done: false }

        console.log(iterator.next());
        // { value: 3, done: false }

        console.log(iterator.next());
        // { value: undefined, done: true }

next() 每呼叫一次，就取得下一個元素。 

value → 目前取得的值
        done  → 是否已經迭代完成

可以簡單理解 for...of 幫我們自動重複呼叫 next()，直到 done === true。

樣板字面值 Template Literals vs 字串字面值 String Literals

一般的 String Literal 使用單引號 ' ' 或雙引號 " "。 

let name = "Kevin";
        let text = "Hello " + name + "!";

        console.log(text); // Hello Kevin!

ES6 新增 Template Literal， 使用反引號 ` ` 建立字串。 

let name = "Kevin";

        let text = `Hello ${name}!`;

        console.log(text); // Hello Kevin!

${ } 可以直接把變數或 Expression 放進字串中。 

let a = 10;
        let b = 20;

        console.log(`結果是 ${a + b}`);
        // 結果是 30
多行字串

Template Literal 也可以直接換行， 不需要自己加入 \n。 

let text = `第一行
        第二行
        第三行`;

簡單記：
" " / ' ' → 一般 String Literal
` ` → Template Literal
${expression} → 把變數或運算結果插入字串

Python 對比
# Python f-string
        name = "Kevin"
        text = f"Hello {name}!"

        // JavaScript Template Literal
        let text = `Hello ${name}!`;

擴展運算子 Spread Operator

Spread Operator 使用三個點 ...， 可以把 Array 或 Object 的內容展開。

展開 Array
const numbers = [10, 20, 30];

        console.log(...numbers);
        // 相當於：
        console.log(10, 20, 30);
為什麼 Math.max() 要使用 ...？

Math.max() 要接收的是「多個獨立參數」， 不是一整個 Array。 

const numbers = [10, 20, 30];

        Math.max(numbers);     // ❌ NaN

        Math.max(...numbers);  // ✅ 30

        // 相當於：
        Math.max(10, 20, 30);

因為 numbers 本身是一個 Array 值： 

numbers
        ↓
        [10, 20, 30]          // 一個 Array

        ...numbers
        ↓
        10, 20, 30            // 展開成三個值
和 Python 對比

Python 的 max() 本身就可以直接接收 Iterable， 所以可以直接傳入 List： 

numbers = [10, 20, 30]

        max(numbers)   # ✅ 30

Python 其實也有類似 Spread 的功能，使用 *： 

print(*numbers)

        # 相當於
        print(10, 20, 30)

所以不是 JavaScript 做不到， 而是 Math.max() 的 API 設計和 Python max() 不同。

使用 Spread 合併 Array
const a = [1, 2];
        const b = [3, 4];

        const result = [...a, ...b];

        console.log(result);
        // [1, 2, 3, 4]

傳統也可以使用 concat()： 

const result = a.concat(b);
        // [1, 2, 3, 4]

[...a, ...b] 和 a.concat(b) 在一般 Array 合併時效果很像， Spread 的寫法通常更加直覺、彈性也比較高。

使用 Spread 合併 Object
const a = {
            name: "Kevin",
            age: 20
        };

        const b = {
            age: 21,
            city: "Taipei"
        };

        const result = {...a, ...b};

結果：

{
            name: "Kevin",
            age: 21,
            city: "Taipei"
        }

Object 如果出現相同 Property Key， 後面展開的值會覆蓋前面的值。 

{...a, ...b}
            ↑
            後面的 b.age 覆蓋 a.age

Array 則是按照順序加入元素， 即使值相同也不會互相覆蓋。 

const a = [1, 2];
        const b = [2, 3];

        const result = [...a, ...b];

        // [1, 2, 2, 3]

簡單記：
...array → 展開元素
[...a, ...b] → 合併 Array
{...a, ...b} → 合併 Object，同 key 後面的覆蓋前面的

可變參數 Variadic Function 與 Rest Parameter

Function 的參數數量不一定要固定。 JavaScript 可以使用 ...args（Rest Parameter） 把傳入的多個參數收集成一個 Array。 

function test(...args) {
            console.log(args);
        }

        test(10, 20, 30);

        // args = [10, 20, 30]

這也是為什麼像 Math.max() 可以接受不同數量的參數： 

Math.max(10, 20);
        Math.max(10, 20, 30);
        Math.max(10, 20, 30, 40);
Rest 和 Spread 的差別

兩個都使用 ...，但方向剛好相反： 

Rest Parameter：
        1, 2, 3
        ↓ 收起來
        [1, 2, 3]


        Spread：
        [1, 2, 3]
        ↓ 展開
        1, 2, 3
        
function test(...args) {  // Rest：收起來
            console.log(args);
        }

        const numbers = [10, 20, 30];

        test(...numbers);         // Spread：展開
和 Python / Java 對比
// JavaScript
        function test(...args) {}

        // Python
        def test(*args):
            pass

        // Java
        void test(int... args) {}

簡單記：
...args 放在 Function 參數 → Rest，把多個參數收起來
...array 放在呼叫 Function 時 → Spread，把 Array 展開

箭頭函式 Arrow Function

Arrow Function 是 ES6 新增的 Function 寫法， 使用 =>，在現代 JavaScript 中非常常見， 尤其常用來寫 Callback Function。

基本格式

一般 Function Expression：

const add = function(a, b) {
            return a + b;
        };

改成 Arrow Function：

const add = (a, b) => {
            return a + b;
        };

主要就是把 function 改成 =>。

Arrow Function 的簡寫

如果 Function 裡面只有一個 Expression， 可以省略 {} 和 return。 

const add = (a, b) => {
            return a + b;
        };

        // 可以簡寫成：

        const add = (a, b) => a + b;

當省略 {} 時， Arrow Function 會自動 return 後面的 Expression。 

const double = x => x * 2;

        double(5); // 10

如果使用 {}，就代表要寫 Function Body， 可以寫很多行，但不會自動 return， 想回傳值就要自己寫 return。 

const calculate = (a, b) => {
            const sum = a + b;
            const result = sum * 2;

            return result;
        };

        calculate(2, 3); // 10

簡單記： 

() => expression
            ↑
            自動 return


        () => {
            多行程式;
            多行程式;

            return value; // 想回傳就自己寫
        }
參數的 ()

如果只有一個參數， 參數外面的 () 可以省略。 

const double = (x) => x * 2;

        // 可以寫成：

        const double = x => x * 2;

如果沒有參數或有兩個以上參數，就需要 ()。 

() => console.log("Hello");

        (a, b) => a + b;
和 Python lambda 對比
// JavaScript
        const add = (a, b) => a + b;

        // Python
        add = lambda a, b: a + b

兩者概念很像，但是 JavaScript Arrow Function 可以使用 {} 寫多行程式。 

// JavaScript 可以這樣
        const calculate = (a, b) => {
            const result = a + b;
            console.log(result);
            return result;
        };

Python lambda 則只能寫一個 Expression。

Arrow Function 常用在哪裡？

Arrow Function 非常常拿來寫 Callback， 因為寫法比一般 Function 簡短。 

const numbers = [1, 2, 3];

        // 一般 Function
        numbers.map(function(x) {
            return x * 2;
        });

        // Arrow Function
        numbers.map(x => x * 2);

所以之前學過的 map()、filter()、 forEach() 都很常搭配 Arrow Function。

一般 Function 和 Arrow Function 的 this 差別

除了語法比較短以外， Arrow Function 還有一個非常重要的差別： Arrow Function 沒有自己的 this。

先記住： 

一般 Function
        → 有自己的 this
        → this 是誰，跟 Function「怎麼被呼叫」有關

        Arrow Function
        → 沒有自己的 this
        → 直接使用外層的 this
先理解一般 Function 的 this

this 可以理解成： 「這次執行 Function 時，目前綁定的 Object 是誰？」 

const user = {
            name: "Kevin",

            sayHi: function() {
                console.log(this.name);
            }
        };

        user.sayHi(); // Kevin

因為這次是透過 user.sayHi() 呼叫， 所以 sayHi 裡面的 this 是 user。 

user.sayHi()
        ↑
        this = user

一般 Function 被呼叫時，會得到一個 this 值；這個 this 是誰，取決於呼叫方式。

call()：手動指定 this

call() 是 Function 的方法， 可以呼叫 Function，並手動指定這次的 this。 

function introduce() {
            console.log(this.name);
        }

        const user = {
            name: "Kevin"
        };

        introduce.call(user);

        // Kevin

可以理解成：

introduce.call(user)
                    ↓
        執行 introduce()
        並指定 this = user

所以 Function 可以搭配不同 Object： 

const user1 = { name: "Kevin" };
        const user2 = { name: "Tom" };

        introduce.call(user1); // Kevin
        introduce.call(user2); // Tom
為什麼老師要講 setTimeout()？

setTimeout() 是瀏覽器提供的功能， 可以讓一個 Callback Function 延遲一段時間後執行。 

setTimeout(function() {
            console.log("Hello");
        }, 1000);

        // 約 1 秒後執行

老師使用它，是為了展示： 一般 Function 和 Arrow Function 對 this 的處理不同。

一般 Function 當 Callback 的問題
const obj = {
            a: 1
        };

        function test() {

            console.log(this.a); // 1

            setTimeout(function() {
                console.log(this.a);
            }, 1000);
        }

        test.call(obj);

第一次： 

test.call(obj)
            ↓
        test 裡面的 this = obj
            ↓
        this.a = 1

但是 setTimeout 裡面又建立了一個一般 Function： 

function() {
            console.log(this.a);
        }

普通 Function 的 this 會根據「這次 Function 怎麼被呼叫」決定， 不會自動沿用外層的 this；Arrow Function 則會沿用外層的 this。


因此 setTimeout() 執行普通 Callback 時， 在瀏覽器中 this 通常是 window， 而不是外層 Function 的 this。


※ Java 的 this 通常代表目前的 instance； JavaScript 普通 Function 的 this 則依呼叫方式決定。


JavaScript 普通 Function 的 this 不是看「誰在使用這個 Function」， 而是看 Function 執行時的呼叫方式。 例如 user.sayHi() → this = user； sayHi.call(user) → 手動指定 this = user； 而 sayHi() 是直接呼叫，沒有前面的 Object。 所以判斷 this 時，要看「怎麼呼叫」，而不是看「Function 屬於誰或被誰使用」。

Arrow Function 解決 this 的問題

如果改成 Arrow Function： 

const obj = {
            a: 1
        };

        function test() {

            console.log(this.a); // 1

            setTimeout(() => {
                console.log(this.a); // 1
            }, 1000);
        }

        test.call(obj);

執行流程： 

test.call(obj)

        ↓
        test 的 this = obj

        ↓
        setTimeout 裡使用 Arrow Function

        ↓
        Arrow Function 沒有自己的 this

        ↓
        往外使用 test 的 this

        ↓
        this = obj

        ↓
        this.a = 1

這就是為什麼 Callback 很常使用 Arrow Function。

this 和 Scope 不要搞混

Arrow Function 沒有自己的 this， 不代表它沒有自己的 Scope。

Function 本來就可以讀取外層 Scope 的變數： 

let a = 10;

        function test() {
            console.log(a); // 10
        }

Arrow Function 也一樣： 

let a = 10;

        const test = () => {
            console.log(a); // 10
        };

所以外面的變數本來就可以往裡面找。 Arrow Function 真正特殊的地方是 this。

Chapter 8 瀏覽器中的 JS

甚麼是 DOM？

DOM = Document Object Model（文件物件模型） Document 指的是「目前這個網頁文件」。 瀏覽器解析 HTML 後，建立 DOM； DOM 是一個 Tree（樹狀）的資料結構， 讓 JavaScript 可以操作網頁。 例如： 
        html
        ├── head
        └── body
            ├── nav
            │   ├── img
            │   └── ul
            │       ├── li
            │       ├── li
            │       └── li
            └── section
這種結構稱為 DOM Tree。 每一個 HTML 元素都可以看成一個 Node（節點）。 例如： 
        document → root node（整個 DOM 的根節點）
        html → document element（HTML 文件的最外層元素）
        body → node
        ul → parent node（父節點）
        li → child node（子節點）
        img → leaf node（沒有子節點）
DOM 是 W3C 等 Web 標準所定義的一套模型， 瀏覽器會按照這些標準，把 HTML 建立成 DOM。 JavaScript 可以透過： 
        document
取得目前網頁的 DOM。 例如在瀏覽器 Console 輸入： 
        document
就可以看到目前網頁的 document 物件。

DOM 的 API

API = Application Programming Interface（應用程式介面） 簡單來說： 「程式提供給其他程式使用的一組功能與規則。」 例如瀏覽器提供 DOM API， 讓 JavaScript 可以操作網頁。 
        document.getElementById("title")
意思是： JavaScript → 使用 DOM API → 找到網頁中的某個 HTML 元素。
為什麼有些 API 有 ()，有些沒有？
因為 API 不一定都是 Function。 API 可以提供： 1. Property（屬性） 2. Method（方法） 例如： 
        document.title
title 是 Property， 只是「取得一個值」，所以不用 ()。 而： 
        document.getElementById("title")
getElementById 是 Method， 需要「執行一個動作」，所以要加 ()。 簡單記： Property → 看資料 → 通常沒有 () Method → 做事情 → 通常有 ()
Web API
DOM API 只是 Web API 的其中一種。 瀏覽器還提供很多其他 API，例如： 
        DOM API       → 操作網頁
        Fetch API     → 發送 HTTP Request
        Geolocation   → 取得位置
        Web Storage   → 儲存資料
所以 API 不等於 Function。 而是「一整套提供給程式使用的功能與規則」， 裡面可能包含 Property、Method、Object 等。

甚麼是 BOM？

BOM = Browser Object Model（瀏覽器物件模型） DOM 主要負責「網頁內容」， BOM 主要負責「瀏覽器本身」。 瀏覽器中最主要的全域物件是： 
        window
例如： 
        window.document
        window.location
        window.history
        window.navigator
        window.screen
其中： 
        window.document
就是我們前面使用的 DOM document。 因為 window 是瀏覽器中的 Global Object， 所以很多時候 window 可以省略： 
        window.document
        document

        window.location
        location

        window.alert("Hello")
        alert("Hello")
效果基本相同。
常見的 BOM
1. location 取得或修改目前網址： 
        window.location.href
也可以簡寫： 
        location.href
2. history 操作瀏覽器的歷史紀錄： 
        history.back()
回到上一頁。 
        history.go(-1)
也可以回到上一頁。 3. navigator 取得瀏覽器、裝置等相關資訊： 
        navigator
4. screen 取得使用者螢幕相關資訊： 
        screen.width
        screen.height

window 與全域變數

在瀏覽器傳統 script 中： 使用 var 宣告的全域變數，通常會成為 window 的 Property。 例如： 
        var name = "Kevin";

        console.log(window.name);
但是 let 和 const 不會： 
        let age = 20;

        console.log(window.age); // undefined
注意： 這跟 Function Scope 沒有關係。 var 如果寫在 Function 裡面， 才會因為 Function Scope 而不是全域變數。 
        function test() {
            var x = 10;
        }

        console.log(window.x); // undefined

DOM 和 BOM 的差別

DOM → 管理「網頁」 例如： 
        document
        HTML
        body
        div
        button
        img
可以用 JavaScript 修改網頁內容。 BOM → 管理「瀏覽器」 例如： 
        window
        location
        history
        navigator
        screen
可以取得網址、歷史紀錄、瀏覽器資訊等。 簡單記： DOM = 網頁裡面的東西 BOM = 瀏覽器提供的環境 而在瀏覽器 JavaScript 中， window 是最主要的 Global Object， document 則是 window 裡面用來操作 DOM 的物件。

實作練習：碼錶

使用 setInterval() 讓函數每隔一段時間重複執行： 


        interval = setInterval(timer, 10);

代表每 10ms 執行一次 timer。

使用 clearInterval() 停止： 


        clearInterval(interval);

注意：每次 setInterval() 都會建立新的計時器， 所以要避免重複按 Start： 


        if (interval === null) {
            interval = setInterval(timer, 10);
        }

停止後記得自己設回 null： 


        clearInterval(interval);
        interval = null;

重點：setInterval() = 重複執行；clearInterval() = 停止重複執行。

實作練習：剪刀石頭布

使用陣列存放剪刀、石頭、布，搭配 Math.random() 隨機產生電腦的選擇。 


        let choices = ['Stone', 'Paper', 'Scissors'];

        let computerChoice =
            choices[Math.floor(Math.random() * 3)];

使用 if / else if 比較玩家與電腦的選擇，判斷輸贏。

使用 querySelectorAll() 取得所有按鈕，再使用 forEach() 為每個按鈕加入點擊事件。 


        let buttons = document.querySelectorAll('.pssButton');

        buttons.forEach(button => {
            const value = button.value;
            button.onclick = () => onClickPSS(value);
        });

重點：Math.random() 產生隨機結果； querySelectorAll() 取得多個元素； forEach() 逐一處理； onclick 處理使用者點擊。

實作練習：狗狗產生器

使用 fetch() 從 API 取得隨機狗狗圖片，練習非同步與 Promise。 


        const dogImageDiv = document.getElementById('dogImage')
        const dogButton = document.getElementById('dogButton')

        const getNewDog = () => {
            fetch('https://dog.ceo/api/breeds/image/random')
                .then(response => response.json())
                .then(json => {
                    dogImageDiv.innerHTML = `<img src='${json.message}'>`
                })

            console.log('得到狗狗!')
        }

        dogButton.onclick = () => getNewDog()
fetch 與 Promise

fetch() 是非同步的，不會等待資料回來才繼續執行，而是先回傳 Promise。

Promise 有三種狀態：pending（等待）、fulfilled（成功）、rejected（失敗）。

.then()

Promise 完成後，結果會傳給第一個 .then() 當參數。 


        fetch(url)
            .then(response => response.json())
            .then(json => {
                console.log(json)
            })

流程：fetch 結果 → 第一個 .then() 的參數 → return 的結果 → 下一個 .then() 的參數。

多個 .then() 就像流水線，上一個 .then() return 的結果可以交給下一個 .then()。

非同步的重要觀念

        fetch(url).then(...)

        console.log('得到狗狗!')

console.log 不一定會等 fetch 完成，所以「得到狗狗!」可能會比狗狗資料更早出現。

Component 組件

Component 是什麼？

Component（組件）就是把 UI 拆成一個個可以重複使用的小部分。

React Component 主要有兩種寫法：

  • Function Component：現在最常使用
  • Class Component：較舊的寫法，現在比較少使用

建立 Function Component

一個 Function 可以定義一個 Component，並 return 要顯示的 JSX。 


        function MyComponent() {
            return <h1>Hello</h1>
        }

Component 名稱必須使用大寫開頭，通常使用 PascalCase。 


        MyComponent    // Component
        myComponent    // 不應這樣命名 Component

因為 JSX 透過大小寫區分： 


        <div>              // HTML element
        <MyComponent />    // React Component

使用 Component

建立 Component 後，可以在 JSX 中像標籤一樣使用： 


        <MyComponent />

沒有 children 時，通常使用 self-closing 寫法。 


        <MyComponent />

        等同於：

        <MyComponent></MyComponent>

JSX 是什麼？

JSX = JavaScript XML，是一種可以在 JavaScript 中寫類似 HTML 結構的語法。 


        const title = <h1>Hello</h1>

JSX 看起來像 HTML，但它不是 HTML，也不是普通 JavaScript 語法。 開發工具會將 JSX 轉換成 JavaScript，最後由 React 建立對應的 DOM 畫面。 

        JSX
        ↓
        Vite / React 編譯工具
        ↓
        JavaScript
        ↓
        React
        ↓
        DOM 畫面

App 根組件

React 專案通常會把 App 當作 Root Component（根組件）， 其他 Component 再放進 App，形成 Component Tree。 

        App
        ├── Header
        ├── Main
        │   ├── Product
        │   └── Product
        └── Footer

包住其他 Component 的稱為 Parent Component， 被包在裡面的稱為 Child Component。

一個 Component 一個檔案

常見做法是把不同 Component 分成不同檔案， 檔案名稱通常和 Component 名稱相同。 

        src/
        ├── App.jsx
        ├── Header.jsx
        ├── Footer.jsx
        └── Product.jsx

需要使用其他檔案的 Component 時，再使用 import。 


        import Header from "./Header.jsx"

VS Code 有時可以自動幫忙加入 import。

export / import

export 和 import 是 JavaScript ES Module 語法，不是 JSX 語法。

export default 表示這個檔案的「預設匯出」。 


        function App() {
            return <h1>Hello</h1>
        }

        export default App

其他檔案就可以： 


        import App from "./App.jsx"
Default Export vs Named Export

Default Export：一個 Module 只能有一個。


        export default App

        import App from "./App.jsx"

Named Export：可以有很多個，import 時使用 { }。


        export function Header() {}
        export function Footer() {}

        import { Header, Footer } from "./Components.jsx"

main.jsx 的作用

main.jsx 是 React 專案的主要 JavaScript 入口。 


        ReactDOM.createRoot(
            document.getElementById("root")
        ).render(
            <App />
        )

document.getElementById("root") 找到 index.html 中的： 


        <div id="root"></div>

createRoot() 建立 React Root， render() 再把 App Component 渲染到這個 root 裡。 

        index.html 的 #root
                ↓
        React createRoot()
                ↓
        <App />
                ↓
        整個 Component Tree
                ↓
        DOM 畫面

React.StrictMode

StrictMode 是 React 開發時用來幫忙檢查潛在問題的工具， 不是負責把 React 轉成 HTML。 


        <React.StrictMode>
            <App />
        </React.StrictMode>

它通常包住 App，幫助開發時提早發現一些不好的 React 寫法。

type="module"


        <script type="module" src="/src/main.jsx"></script>

type="module" 告訴瀏覽器這支 JavaScript 使用 ES Module， 因此可以使用 import / export。

Component 注意事項

  • Component 名稱使用大寫開頭，例如 MyComponent。
  • 通常使用 PascalCase 命名。
  • Component 不要定義在另一個 Component 裡面。
  • 常見做法是一個 Component 一個檔案，方便管理。
  • JSX 中沒有內容的 Element / Component 要使用 self-closing，例如 <App />。

Vite 開發伺服器支援快速更新。 修改並儲存 React 程式後，瀏覽器通常會立即看到新的結果， 不需要重新啟動 Server。

        ↓
        <App />
        ↓

JSX

JSX 只能有一個最外層元素

React Component 一次 return 的 JSX 必須有一個 Root（最外層）。

錯誤：


        return (
            <h1>Hello</h1>
            <p>World</p>
        )

可以使用 div 包起來：


        return (
            <div>
                <h1>Hello</h1>
                <p>World</p>
            </div>
        )

這是 JSX / React 的結構規則， 不是因為 JavaScript 只能 return 一個物件。

Fragment

如果只是為了包住多個元素，不希望 DOM 多出一個 div， 可以使用 React Fragment： 


        return (
            <>
                <h1>Hello</h1>
                <p>World</p>
            </>
        )

<></> 是 Fragment 的簡寫， 可以包住多個 JSX 元素，但不會產生額外的 HTML Element。

return 與括號

JSX 有多行時，通常使用 ( ) 包起來。 


        return (
            <h1>Hello</h1>
        )

單行也可以直接寫：


        return <h1>Hello</h1>

注意：不要在 return 後直接換行再寫 JSX， JavaScript 可能會自動把 return 當成結束。

在 JSX 中使用 JavaScript

JSX 使用 { } 進入 JavaScript Expression。 


        const name = "Kevin"

        return <h1>Hello {name}</h1>

也可以運算：


        <p>{10 + 20}</p>

{ } 裡面主要放 Expression（會產生值的 JavaScript 表達式）。

在屬性中使用 JavaScript

JSX 的屬性也可以使用 { }。 


        const text = "請輸入名字"

        <input
            type="text"
            placeholder={text}
        />

HTML 的 input 是輸入框， type 決定輸入類型，placeholder 是尚未輸入時顯示的提示文字。

JSX 屬性名稱

JSX 比較接近 JavaScript，因此部分 HTML 屬性名稱會改成 JavaScript 風格， 通常使用 camelCase。

HTML JSX
class className
for htmlFor
onclick onClick

例如：


        <label htmlFor="name">名字</label>
        <input id="name" className="inputBox" />

label 的 for / htmlFor 用來指定這個 label 對應哪一個表單元素。

Inline Style

JSX 可以使用 style 屬性加入 Inline Style， 但傳入的是 JavaScript Object，不是一般 CSS 字串。 


        <h1 style={{ color: "red", fontSize: "30px" }}>
            Hello
        </h1>

兩層大括號可以拆開理解：

        style={ { color: "red" } }
            ↑
            JavaScript Object

            ↑               ↑
        外面的 { } = JSX 進入 JavaScript

所以 {{ }} 不是特殊語法， 只是「JSX 的 { } 裡面剛好放了一個 JavaScript Object」。

Style Object 的屬性通常使用 camelCase： 


        font-size        → fontSize
        background-color → backgroundColor

使用 CSS 檔案

實際專案更常把樣式寫在 CSS 檔案。 

        App.jsx
        App.css

在 Component 中：


        import "./App.css"

原生瀏覽器 JavaScript 本身不是直接用這種方式載入 CSS。 Vite 會處理 CSS import，最後讓 CSS 套用到網頁。

CSS 檔案不一定要和 Component 同名， 同名只是常見的整理方式。

React 事件處理

一般 JavaScript 可能會先取得 DOM，再綁定事件： 


        const button = document.getElementById("btn")

        button.addEventListener("click", handleClick)

React 通常不需要自己 getElementById 綁定事件， 而是直接在 JSX 宣告： 


        function handleClick() {
            console.log("Clicked")
        }

        return (
            <button onClick={handleClick}>
                Click
            </button>
        )

這是 React 常用的事件處理方式。

為什麼 onClick 不加 ()？

正確：


        onClick={handleClick}

代表把 Function 本身交給 React， 等使用者 Click 時再執行。

如果寫：


        onClick={handleClick()}

() 代表現在就呼叫 Function， 因此在 Render 時就會直接執行。 

        handleClick    → Function 本身

        handleClick()  → 立即呼叫 Function

使用 Arrow Function

如果需要傳參數，可以包一層 Arrow Function： 


        <button onClick={() => handleClick("Kevin")}>
            Click
        </button>

這樣 handleClick("Kevin") 不會立即執行， 而是 Click 後才執行。

Event Object

React 執行事件 Function 時，可以取得事件物件 e。 


        function handleClick(e) {
            console.log(e)
        }

e（event）包含這次事件的相關資訊， 例如是哪個元素觸發事件。 


        function handleClick(e) {
            console.log(e.target)
        }
React Event Handler 的參數

React Event Handler 觸發時，React 會自動傳入 Event Object， 通常使用 e (滑鼠座標, 點擊按鈕) 來接收。 


        onClick={(e) => console.log(e)}

如果不需要 Event，只想自己傳參數，可以使用空的 Arrow Function 包住： 


        onClick={() => handleClick("Kevin")}

如果 Event 和自己的參數都需要： 


        onClick={(e) => handleClick(e, "Kevin")}

簡單記：不需要 Event → () =>； 需要 Event → (e) =>。

JavaScript Function 參數型別

JavaScript 的參數不需要宣告型別。 


        function add(num) {
            return num + 1
        }

JavaScript 沒有 Python 的 num: int 寫法。

        Java:
        int num

        Python:
        num: int

        JavaScript:
        num

        TypeScript:
        num: number

如果希望 JavaScript 有更完整的型別系統， 通常會使用 TypeScript。

JSX 簡單整理

  • Component 的 JSX 必須有一個最外層 Root。
  • 不想增加 div，可以使用 Fragment <></>。
  • JSX 中使用 { } 放 JavaScript Expression。
  • class → className，for → htmlFor。
  • style={{ }} = JSX 的 { } 裡放 JavaScript Object。
  • React 事件通常直接使用 onClick={function}。
  • function 不加 () 是傳 Function；加 () 是立即呼叫。

JSX 中的陣列

JSX 可以存進變數

JSX 可以先寫在 return 外面，存進 JavaScript 變數。 


        const title = <h1>Hello</h1>

        return (
            <div>{title}</div>
        )

JSX 最後會被轉換成 JavaScript， 所以可以像一般 JavaScript 的值一樣存進變數、放進陣列。

JSX 可以放進 Array


        const items = [
            <p key="1">Apple</p>,
            <p key="2">Banana</p>,
            <p key="3">Orange</p>
        ]

        return <div>{items}</div>

React 可以直接 Render 一個 JSX Element 陣列。

使用 map() 產生 JSX

實際開發更常使用 map()， 把資料 Array 轉換成 JSX Array。 


        const fruits = ["Apple", "Banana", "Orange"]

        return (
            <div>
                {fruits.map((fruit) => (
                    <p key={fruit}>{fruit}</p>
                ))}
            </div>
        )

map() 的 Callback 每次取得一個 item， 回傳一個 JSX Element，最後組成新的 Array。 

        資料 Array
        ["Apple", "Banana", "Orange"]
                ↓ map()
        JSX Array
        [<p>Apple</p>, <p>Banana</p>, <p>Orange</p>]
                ↓
        React Render

key 屬性

使用 Array Render 多個 JSX Element 時， 每個同層級的 Element 應該有唯一且穩定的 key。 


        <p key={fruit.id}>{fruit.name}</p>

key 是 React 專用的提示， 用來辨認「這次的 Element 和上次的哪一個是同一個」。 

        原本：
        1 → Apple
        2 → Banana
        3 → Orange

        刪除 Banana：

        1 → Apple
        3 → Orange

        React 看到 key
        → 知道 1、3 還是原本的元素
        → 知道 2 被刪除了
        → 更正確地更新 UI

所以 key 不只是為了速度， 更重要的是讓 React 正確追蹤每個 Element 的身分。

key 可以是 Number 或 String， 最好使用資料本身穩定且唯一的 id。

為什麼普通 JavaScript Array 不需要 key？

key 不是 JavaScript Array 的規則，而是 React Render List 時的規則。 


        // 普通 JavaScript Array，不需要 key
        const fruits = ["Apple", "Banana", "Orange"]

只有當 React 把 Array 中的資料 Render 成多個 JSX Element 時， 才需要 key 幫助 React 辨認它們。

使用 filter() 過濾資料

filter() 會根據 Callback 回傳的 true / false， 建立一個新的 Array。 


        const numbers = [1, 2, 3, 4, 5]

        const result = numbers.filter((num) => num > 3)

        // [4, 5]

true → 保留
false → 不保留

filter() + map()

React 很常先用 filter() 過濾資料， 再用 map() 轉成 JSX。 


        const products = [
            { id: 1, name: "Apple", price: 20 },
            { id: 2, name: "Banana", price: 10 },
            { id: 3, name: "Orange", price: 30 }
        ]

        return (
            <div>
                {products
                    .filter((product) => product.price > 10)
                    .map((product) => (
                        <p key={product.id}>
                            {product.name}
                        </p>
                    ))}
            </div>
        )
        
        filter() → 決定哪些資料留下
        map()    → 把留下的資料轉成 JSX

與 Python 對照

Python 常見兩種過濾方式：

① List Comprehension（最常見）


        numbers = [1, 2, 3, 4, 5]

        result = [num for num in numbers if num > 3]

② filter()


        result = list(filter(lambda num: num > 3, numbers))

JavaScript：


        const result = numbers.filter((num) => num > 3)

簡單整理

  • JSX 可以存進變數，也可以放進 Array。
  • map()：把資料 Array 轉成 JSX Array。
  • filter()：根據條件過濾 Array。
  • Render List 時，每個同層 Element 要有唯一、穩定的 key。
  • key 是 React 的規則，不是 JavaScript Array 的規則。
  • key 主要幫 React 正確辨認 Element 身分，並有效率地更新 UI。

React 裡的條件判斷

if...else

React 中可以使用一般 JavaScript 的 if...else。 


        function Message() {
            const isLogin = true

            if (isLogin) {
                return <h1>歡迎回來</h1>
            } else {
                return <h1>請先登入</h1>
            }
        }

但 if...else 不能直接寫在 JSX 的 { } 裡， 因為 { } 裡通常需要放 Expression（會產生值的表達式）。

三元運算子

JSX 中需要條件判斷時，很常使用三元運算子。 


        條件 ? true時的值 : false時的值

例如：


        const isLogin = true

        return (
            <div>
                {isLogin ? <h1>歡迎回來</h1> : <h1>請先登入</h1>}
            </div>
        )

在 className 使用三元運算子

className 的值可以透過三元運算子動態決定。 


        <div className={isActive ? "active" : "inactive"}>
            Hello
        </div>

如果有固定的 Class，又想根據條件增加其他 Class， 常使用 Template Literal（反引號字串）。 


        <div className={`box ${isActive ? "active" : "inactive"}`}>
            Hello
        </div>

其中： 

        { }  → JSX 進入 JavaScript

        ` `  → JavaScript Template Literal

        ${ } → 在 Template Literal 中插入 JavaScript 值

所以外面的 { } 不能拿掉： 


        className={`box ${isActive ? "active" : "inactive"}`}
                ↑
                這整個是 JavaScript Expression

&& 條件渲染

如果只想在條件成立時顯示某個 JSX，可以使用 &&。 


        const isLogin = true

        return (
            <div>
                {isLogin && <h1>歡迎回來</h1>}
            </div>
        )

isLogin 為 Truthy → 顯示右邊的 JSX。
isLogin 為 Falsy → 不執行 / 不取右邊，整個表達式回傳左邊的 Falsy 值。

&& 真正的 JavaScript 規則

&& 不只是 React 的條件顯示語法，而是 JavaScript 本身的運算子。

&& 會先檢查左邊： 

        左邊是 Falsy
        → 直接回傳左邊

        左邊是 Truthy
        → 繼續計算並回傳右邊

例如：


        false && "Hello"   // false

        true && "Hello"    // "Hello"

        0 && "Hello"       // 0

        5 && "Hello"       // "Hello"

React 只是利用 && 的這個 JavaScript 特性來做條件渲染。

簡單整理

  • if...else：一般 JavaScript 條件判斷。
  • 三元運算子：需要「二選一」時很常使用。
  • &&：只想在條件成立時顯示東西。
  • className 可以使用三元運算子動態決定 Class。
  • Template Literal 可以使用 ${ } 插入 JavaScript 值。

Props 屬性

Props 是什麼？

React Component 雖然像 Function，但在 JSX 中不是用 Component("Kevin") 的方式傳參數，而是透過 Props 傳入資料，讓同一個 Component 可以接收不同資料並重複使用。

Props = Properties。

Props 是 React 中「父 Component 傳資料給子 Component」的方式。 

        Parent Component
            ↓ Props
        Child Component

可以把 Component 想成 Function： 


        function Greeting(props) {
            return <h1>Hello {props.name}</h1>
        }

父 Component 使用：


        <Greeting name="Kevin" />

React 會把傳入的資料整理成 props Object： 


        props = {
            name: "Kevin"
        }

傳入多個 Props


        <User name="Kevin" age={20} student={true} />

子 Component 可以取得：


        function User(props) {
            return (
                <p>
                    {props.name} - {props.age}
                </p>
            )
        }

Props 可以傳入 String、Number、Boolean、Array、Object、 Function、JSX 等各種 JavaScript 值。

Props Destructuring（解構）

因為 props 本身是一個 Object，所以可以使用 Object Destructuring。

原本：


        function User(props) {
            return <p>{props.name} - {props.age}</p>
        }

可以簡化成：


        function User({ name, age }) {
            return <p>{name} - {age}</p>
        }

name、age 是根據 Property 名稱取得， 所以順序不重要，但名稱要對應。 


        function User({ age, name }) {
            // 一樣可以
        }
為什麼解構是 { }，不是 ...？

{ } 是 Object Destructuring（物件解構）。 


        const user = {
            name: "Kevin",
            age: 20
        }

        const { name, age } = user

相當於：


        const name = user.name
        const age = user.age

... 則是 Spread / Rest Syntax，是另一個功能。 


        const user = { name: "Kevin", age: 20 }

        const copy = { ...user }

Props 預設值

使用解構時，也可以直接設定預設值。 


        function User({ name = "Guest", age = 18 }) {
            return <p>{name} - {age}</p>
        }

如果父 Component 沒有傳入 name，就會使用 "Guest"。

Props 可以傳 Function

Function 也是 JavaScript 的值，所以也可以透過 Props 傳入。 


        function Parent() {

            function sayHello() {
                alert("Hello")
            }

            return <Button handleClick={sayHello} />
        }

        function Button({ handleClick }) {
            return (
                <button onClick={handleClick}>
                    Click
                </button>
            )
        }
        
        Parent
        ↓ 傳 sayHello
        Button
        ↓
        使用者 Click
        ↓
        執行 sayHello

HTML Attribute vs React Props

如果寫的是 HTML Element： 


        <input type="text" placeholder="Name" />

type、placeholder 是 HTML Element 的屬性。

如果是自己建立的 Component：


        <User name="Kevin" age={20} />

name、age 則是傳給 User Component 的 Props。

Props 通常是由上往下傳

Props 的基本資料流是 Parent → Child。 

        App
        ↓ props
        User
        ↓ props
        Avatar

Child 不應直接修改收到的 Props。 如果資料需要改變，通常由擁有該資料的 Component 管理。

傳入 JSX：children

Component 的開始與結束標籤中間，也可以放 JSX。 


        <Card>
            <h1>Hello Kevin</h1>
        </Card>

中間的內容會透過一個特殊的 Prop：children 傳給 Card。 


        function Card({ children }) {
            return (
                <div className="card">
                    {children}
                </div>
            )
        }
        
        <Card>
            <h1>Hello</h1>
        </Card>

                ↓

        children = <h1>Hello</h1>

Composition（組合）

使用 Component 包住其他 Component / JSX， 再透過 children 組合 UI，稱為 Composition。 


        <Card>
            <Title />
            <Body />
        </Card>

Composition 是 React 很常見的設計方式， 可以讓 Component 更容易重複使用。

Props 簡單整理

  • Props = Parent 傳資料給 Child。
  • Props 本身是一個 Object。
  • 可以一次傳很多 Props。
  • 可以傳 String、Number、Object、Array、Function、JSX 等。
  • { name, age } 是 Object Destructuring，不是 Spread。
  • Props 通常由上往下傳：Parent → Child。
  • Component 中間的 JSX 會透過 children 傳入。
  • 使用 children 組合 Component 是 React 常見的 Composition。

State

為什麼需要 State？

一般 JavaScript 變數改變時，React 不會因此重新 Render， 所以畫面不會自動跟著改變。 


        let clicks = 0

        clicks = clicks + 1

clicks 的值雖然改變了，但 React 不知道需要更新 UI。

因此 React 提供 State，讓 Component 可以記住資料， 並在 State 更新後重新 Render UI。

State 是什麼？

State 是 React 幫 Component 記住並管理的「狀態值」。

State value 本身仍然只是普通的 JavaScript 值， 可以是 Number、String、Boolean、Array、Object 等。 


        useState(0)
        useState("Kevin")
        useState(false)
        useState([])
        useState({})

特別的是 React 會管理 State， State 更新後 React 會重新 Render Component。

useState()

useState 是 React 提供的 Hook Function， 使用前需要從 React import。 


        import { useState } from "react"

VS Code 有時會自動幫忙加入 import。

useState() 的參數是 State 的初始值。 


        useState(0)

useState() 會回傳一個 Array，裡面有兩個東西： 

        [
            目前的 State value,
            更新 State 的 Function
        ]

所以通常使用 Array Destructuring：


        const [clicks, setClicks] = useState(0)
        
        clicks
        → 目前的 State value

        setClicks
        → 更新 State 的 Function

        0
        → State 的初始值

Array Destructuring

[clicks, setClicks] 是 JavaScript 的 Array Destructuring， 不是 React 特殊語法。 


        const [clicks, setClicks] = useState(0)

Array Destructuring 是「順序重要，名稱不重要」。 

        第一個 → State value
        第二個 → Setter Function

只是 React 慣例會把 Setter 命名為 set + State名稱。 


        const [count, setCount] = useState(0)
        const [name, setName] = useState("")
        const [login, setLogin] = useState(false)

Object Destructuring 則是名稱重要、順序不重要。

Setter Function

useState 回傳的第二個值是一個 Function， 通常稱為 Setter Function。 


        const [clicks, setClicks] = useState(0)

例如：


        setClicks(5)

表示要求 React 把這個 State 更新成 5。 

        setClicks(5)
            ↓
        React 收到 State 更新
            ↓
        State 更新
            ↓
        重新 Render Component
            ↓
        UI 使用新的 State

Setter 不是單純執行 clicks = 5， 而是 React 提供的 Function， 背後會連接 React 的 State 管理與重新 Render 機制。

State 範例


        function Counter() {

            const [clicks, setClicks] = useState(0)

            function handleClick() {
                setClicks(clicks + 1)
            }

            return (
                <button onClick={handleClick}>
                    點擊次數：{clicks}
                </button>
            )
        }

流程：

        初始：
        clicks = 0
        ↓
        畫面：點擊次數 0

        Click
        ↓
        setClicks(clicks + 1)
        ↓
        React 更新 State
        ↓
        重新 Render
        ↓
        clicks = 1
        ↓
        畫面：點擊次數 1

一個 Component 可以有多個 State

一個 Component 可以建立很多個 State， 每個 State 負責不同的狀態。 


        function User() {

            const [name, setName] = useState("")
            const [age, setAge] = useState(18)
            const [isLogin, setIsLogin] = useState(false)

            // ...
        }

可以把一個 State 暫時理解成一個 「由 React 管理、改變時會讓 UI 重新 Render 的特殊變數」。

不同 Component 的 State 互相獨立

每個 Component Instance 都可以擁有自己的 State。 


        <Counter />
        <Counter />
        <Counter />

三個 Counter 通常各自記住自己的 clicks， 點第一個不會自動改變另外兩個。

State 可以透過 Props 傳給 Child

Parent 可以把自己的 State 當成 Props 傳給 Child。 


        function Parent() {

            const [count, setCount] = useState(0)

            return (
                <Child count={count} />
            )
        }

        function Child({ count }) {
            return <p>{count}</p>
        }
        
        Parent State
            ↓
        Props
            ↓
        Child

Render（渲染）是什麼？

Render 可以簡單理解成： React 執行 Component，根據目前的 Props 和 State 計算出要顯示的 JSX， 再更新畫面需要改變的部分。 

        Component
        ↓
        目前的 Props + State
        ↓
        產生 JSX
        ↓
        React 比較並更新 DOM
        ↓
        瀏覽器畫面

注意：Render 不是簡單的「JSX 直接變成 HTML 字串」， 而是 React 根據 JSX 決定 DOM 應該長什麼樣子。

Initial Render 初次渲染

Component 第一次出現在畫面時，React 會進行 Initial Render。 

        Component 第一次執行
        ↓
        useState 使用初始值
        ↓
        產生 JSX
        ↓
        建立 / 更新 DOM
        ↓
        顯示畫面
Re-render 重新渲染

State 更新後，React 會重新執行 Component， 使用新的 State 再計算一次 JSX。 

        setState(...)
        ↓
        State 更新
        ↓
        Component 重新 Render
        ↓
        產生新的 JSX
        ↓
        React 比較前後結果
        ↓
        只更新需要改變的 DOM

useState 背後原理

useState 是 React 提供的 Hook Function， 背後有 React 自己的 State 管理機制。

React 會記住某個 Component 對應的 State， 所以 Component Re-render 時， State 不會每次都重新變回初始值。 

        useState(0)
            ↓
        React 記住這個 State
            ↓
        setState(1)
            ↓
        React 保存新的 State
            ↓
        Re-render
            ↓
        再次 useState(0)
            ↓
        取得 React 保存的 1
        而不是重新變成 0

簡單整理

  • 普通變數改變，不會讓 React 自動重新 Render。
  • State = React 幫 Component 記住並管理的狀態值。
  • useState(初始值) 用來建立 State。
  • useState 回傳 [State value, Setter Function]。
  • Setter Function 更新 State，並讓 React 安排重新 Render。
  • 一個 Component 可以有很多個 State。
  • 不同 Component Instance 的 State 通常互相獨立。
  • State 可以透過 Props 傳給 Child Component。
  • Initial Render = 第一次渲染。
  • Re-render = State 等資料改變後重新計算 UI。
