什麼是radio button? (單選按鈕（Radio Button），一組選項中只能選一個。)

radio button是單選按鈕的意思，通常會搭配label使用，讓使用者可以點擊文字來選擇。

什麼是checkbox? (複選按鈕（Checkbox），一組選項中可以選多個。)

checkbox是複選按鈕的意思，通常會搭配label使用，讓使用者可以點擊文字來選擇。

只有當你要「提交資料到後端」時，才需要。

  • 包在 label 裡：不用 for、id，點文字也能勾選。
  • 不包在 label 裡：需要 for 對應 id，才能讓文字也能點。
  • 沒有包也沒有 for：文字和 checkbox 沒有關聯，只能點 checkbox 本身。

什麼是Meta? (meta 的核心概念就是：「描述某個東西本身的資訊，而不是那個東西本身。」)

Meta是指網頁的元資料，通常會放在head標籤中，包含網頁的描述、關鍵字、作者、版權等資訊。

Description

Description是指網頁的描述，通常會放在meta標籤中，讓搜尋引擎可以了解網頁的內容。

是由開發者（或程式）提供給搜尋引擎和社群平台的頁面摘要，不是 HTML 自動從內文擷取，且 Google 可能視情況改用內文作為搜尋結果描述。

Keywords

Keywords是指網頁的關鍵字，通常會放在meta標籤中，讓搜尋引擎可以了解網頁的內容。

OG

OG是指Open Graph的縮寫，用於定義網頁的社交媒體分享資訊。

OG標籤通常會放在head標籤中，包含網頁的標題、描述、圖片、網址等資訊，讓社交媒體可以正確地顯示網頁的內容。

  • og:title：網頁的標題。
  • og:description：網頁的描述。
  • og:image：網頁的圖片。
  • og:url：網頁的網址。(og:url 用來指定網頁的正式網址，避免同一內容因不同網址被社群平台誤認為不同頁面。)

什麼是跳脫字元?

跳脫字元是指在HTML中使用特殊字元的方式，通常會使用&符號加上字元的名稱或編碼，讓瀏覽器可以正確地顯示特殊字元。

HTML Entities
  • &nbsp;：空格
  • &lt;：小於號
  • &gt;：大於號
  • &amp;：&
  • &quot;：雙引號
  • &apos;：單引號
  • ™：商標

粗體元素

粗體元素是指使用strong標籤或b標籤來將文字加粗，通常會用於強調文字的重要性。

強調元素

強調元素是指使用strong標籤來將文字強調。

strong 表示「內容很重要」並通常顯示為粗體，可以為文字添加語意；b 只是讓文字變粗，不代表具有特殊語意。

斜體元素

斜體元素是指使用i標籤來將文字設為斜體，通常會用於強調文字的語氣或翻譯。

em元素

em元素是指使用em標籤來將文字設為斜體，通常會用於強調文字的語氣或翻譯。

em 表示「內容很重要」並通常顯示為斜體，可以為文字添加語意；i 只是讓文字變斜，不代表具有特殊語意。

什麼是iframe?

iframe是指內嵌框架，可以用來在一個網頁中嵌入另一個網頁。

frameborder="0" 表示不顯示iframe的邊框，但在 HTML5 已不建議使用，現在通常改用 border: none; 來設定。

button
